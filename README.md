# FCdraft

A self-contained football draft game built with plain HTML, CSS and JavaScript.

## Included
- FC-style dark football UI
- Formation selector
- 3 player choices per position
- Rarity system: 90–99 Very Rare, 89 Epic
- In-game coin economy only
- Player market and owned players
- Draft squad and match simulation
- Match history
- Responsive layout
- Browser localStorage persistence

## Important
The included player list is a starter dataset for the prototype. It is not presented as an official complete FC 27 ratings database.

## Run
Open `index.html` in a browser.

No Vercel, Lovable, backend, payment system or external service is required for this prototype.
